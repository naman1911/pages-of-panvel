        Backupsa copy of the whole circle, kept by you

        There's no other copy of the circle's data. Download backup saves everything shared on the site to this phone or computer, in one file: every member, book, saved line, streak and agenda post, exactly as stored, with the date and counts. Keep it somewhere safe, like Google Drive. Once a week, say every Sunday, is plenty.

        If something is ever lost, that file is how it gets put back. Private books live in each person's own record, which only they can read, so they aren't in it. Nothing is uploaded or changed when you download.
